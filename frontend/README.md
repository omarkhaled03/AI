# Passengers Frontend

React + TypeScript frontend (Vite) for the Passenger resource.

## Setup

```bash
npm install
```

Optionally copy `.env.example` to `.env` and set `VITE_API_BASE_URL` (defaults to `http://localhost:8000`).

## Run

```bash
npm run dev
```

## Test

```bash
npm test
```

## Build

```bash
npm run build
```
